# Ansible Jenkins Tomcat Deployment

## Project Overview

This project demonstrates a CI/CD deployment workflow using Jenkins, Maven, Ansible, Apache Tomcat, and AWS EC2.

The project automates the process of building an application, using Ansible for deployment automation, and deploying the application to an Apache Tomcat server.

## Technologies Used

- AWS EC2
- Linux
- Git & GitHub
- Jenkins
- Maven
- Ansible
- Apache Tomcat
- Java
- XML
- SSH
- Bash / Shell Scripting
